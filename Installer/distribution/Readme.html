Installation Guide

Before You Begin

Please ensure you have:

  • macOS 13.0 (Ventura) or newer
  • Apple Pay configured in System Preferences
  • A valid payment card in your Wallet app
  • An iPhone with Face ID (XS or newer)
  • Your iPhone and Mac on the same WiFi network

Installation Process

This installer will:

  • Check your system compatibility
  • Install PhoneUnlocker to your Applications folder
  • Set up necessary permissions
  • Back up any existing installation
  • Make the application ready to use

Quick Setup After Installation

1. Grant Accessibility Permissions

System Preferences → Security & Privacy → Accessibility → Add PhoneUnlocker.app

2. Launch the Application

Applications folder → PhoneUnlocker.app

3. Test the Feature

  • Activate your screensaver (or wait 5 minutes)
  • Click the PhoneUnlocker menu bar icon
  • Click "Verify with iPhone"
  • Complete Face ID authentication
