## Installation Checklist (For End Users)

### Before Installation
- [ ] macOS version 13.0+ (check: Apple menu → About This Mac)
- [ ] Apple Pay configured (System Preferences → Wallet & Apple Pay)
- [ ] Payment card added to Wallet
- [ ] Face ID enabled on iPhone
- [ ] iPhone nearby and on same WiFi
- [ ] Administrator access available

### Installation Steps
- [ ] Download or clone repository
- [ ] Navigate to project directory
- [ ] Run: `bash Installer/install.sh`
- [ ] Wait for build to complete (2-5 minutes)
- [ ] Grant Accessibility permissions when prompted
- [ ] Verify app installed to /Applications
- [ ] Verify menu bar icon appears

### Post-Installation Setup
- [ ] System Preferences → Security & Privacy → Accessibility
- [ ] Confirm PhoneUnlocker is in list and enabled
- [ ] System Preferences → Wallet & Apple Pay
- [ ] Verify payment card is active
- [ ] Test Face ID on iPhone works
- [ ] Activate screensaver manually to test
- [ ] Click menu bar icon
- [ ] Verify "Verify with iPhone" button appears

### Verification Tests
- [ ] Menu bar icon appears in top-right
- [ ] Click menu bar icon opens menu
- [ ] Status shows "Inactive" or "Active"
- [ ] Button responds to clicks
- [ ] iPhone shows Face ID prompt when clicked
- [ ] Face ID completes successfully
- [ ] Screensaver unlocks automatically
- [ ] Success message appears
- [ ] No error messages

### Troubleshooting If Issues
- [ ] Check [TROUBLESHOOTING.md](Docs/TROUBLESHOOTING.md)
- [ ] Verify all prerequisites met
- [ ] Check Apple Pay configuration
- [ ] Verify Accessibility permissions
- [ ] Restart the app
- [ ] Restart your Mac
- [ ] Contact support if still issues
